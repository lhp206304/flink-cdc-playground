# 架构说明

## 一、整体架构

本项目采用 **CDC → Kafka → Flink → Iceberg** 的数据同步架构，Kafka 作为中央数据总线。

```
PostgreSQL(public) ──[Flink CDC Pipeline YAML]──> Kafka(cdc.*) ──┐
                                                                  ├──> Flink Job ──> Iceberg
Kafka 事件生成器 ───────────────────────────────> Kafka(events.*)┘
                                                                  ▲
                                              PostgreSQL(dim) ────┤
                                              (维表: Broadcast/AsyncIO)
```

## 二、链路说明

### 链路 1：PostgreSQL CDC → Kafka（声明式）

- **实现**：Flink CDC 3.x Pipeline API（YAML）
- **源**：PostgreSQL public schema 业务表
- **目标**：Kafka（按表名路由到 cdc.* topic）
- **特性**：多表同步、Schema 演化、Exactly-Once

### 链路 2：Kafka → Iceberg（编程式）

- **实现**：Flink DataStream API（Java）
- **源**：Kafka 中 cdc.* + events.* topic
- **处理**：清洗 → 维表关联 → JOIN → 分流写入
- **目标**：Iceberg（ODS upsert / DWD append）

## 三、维表关联策略

| 维表 | 大小 | 关联方式 | 理由 |
|------|------|---------|------|
| dim_region | < 1000 行 | Broadcast 广播流 | 内存查 Map，毫秒级 |
| dim_user | 万级行 | AsyncIO + JDBC | 不占内存，高并发查询 |

## 四、模块说明

| 模块 | 职责 |
|------|------|
| `data-generator` | Kafka 事件生成 + PostgreSQL 业务数据生成 |
| `flink-jobs` | CDC Pipeline 提交 + Kafka 处理 Job |
| `docker` | Postgres + Kafka 本地环境 |

## 五、配置原则

- 所有连接信息通过**环境变量**注入
- **无硬编码、无回退默认值**，缺失则启动报错
- 本地开发用 `localhost`，Docker 部署用服务名
