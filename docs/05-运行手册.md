# 运行手册

> 本文档是项目的**实操运维手册**，涵盖启动、验证、查询、停止、清理、排查全流程。
> 所有命令均在项目根目录 `/Users/walterlee/Project/flink-cdc-playground` 下执行（除非另有说明）。

---

## 一、启动前检查

启动作业前，逐项确认：

| 检查项 | 命令 | 预期结果 |
|--------|------|---------|
| Docker 运行中 | `docker info \| head -3` | 输出 Server Version |
| 端口 5433 未占用 | `lsof -i:5433` | 无输出（或被 pg-cdc 占用） |
| 端口 9092 未占用 | `lsof -i:9092` | 无输出（或被 kafka 占用） |
| 端口 8888 未占用 | `lsof -i:8888` | 无输出（或被 kafka-ui 占用） |
| 环境变量文件存在 | `test -f .env && echo OK` | 输出 OK |
| JDK 版本 | `java -version 2>&1 \| head -1` | 17.x |
| Maven 版本 | `mvn -version \| head -1` | 3.9.x |

## 二、启动顺序

> **必须按顺序启动**，每步确认成功后再启动下一步。

### 步骤 1：启动 Docker 环境

```bash
cd docker
docker-compose up -d
cd ..
```

验证（等待 10 秒后）：

```bash
docker ps --format "table {{.Names}}\t{{.Status}}"
```

预期输出：

```
NAMES      STATUS
kafka-ui   Up ...
pg-cdc     Up ... (healthy)
kafka      Up ...
```

### 步骤 2：编译项目

```bash
mvn clean package -DskipTests -q
```

预期：无报错，`flink-jobs/target/classes/` 和 `data-generator/target/classes/` 存在。

### 步骤 3：构建 classpath（CDC + DWD 用）

```bash
mvn dependency:build-classpath -pl flink-jobs -Dmdep.outputFile=/tmp/cp.txt -q
mvn dependency:build-classpath -pl data-generator -Dmdep.outputFile=/tmp/dg-cp.txt -q
```

### 步骤 4：生成测试数据

```bash
set -a && source .env && set +a
DG_CP="data-generator/target/classes:$(cat /tmp/dg-cp.txt)"

java -cp "$DG_CP" \
  -Dlog4j2.configurationFile=file:$(pwd)/data-generator/src/main/resources/log4j2.properties \
  com.pipeline.generator.postgres.PostgresDataGenerator
```

运行 10~30 秒后 `Ctrl+C` 停止。验证：

```bash
docker exec pg-cdc psql -U postgres -d ecommerce \
  -c "SELECT 'orders' t, count(*) FROM public.orders \
      UNION ALL SELECT 'payments', count(*) FROM public.payments;"
```

预期：orders 和 payments 都有数据。

### 步骤 5：启动 CDC 同步（PG → Kafka）

> 需要**新终端**，CDC 作业持续运行。

```bash
set -a && source .env && set +a
CP="flink-jobs/target/classes:$(cat /tmp/cp.txt)"

java --add-opens java.base/java.nio=ALL-UNNAMED \
  --add-opens java.base/java.lang=ALL-UNNAMED \
  --add-opens java.base/java.util=ALL-UNNAMED \
  --add-opens java.base/sun.nio.ch=ALL-UNNAMED \
  -cp "$CP" \
  -Dlog4j.configuration=file:$(pwd)/flink-jobs/src/main/resources/log4j.properties \
  com.pipeline.flink.cdc.PostgresCdcToKafka
```

日志出现 `Pipeline submitted successfully` 表示成功。

验证（另开终端）：

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 --list | grep cdc
```

预期：出现 `cdc.orders`、`cdc.payments`、`cdc.order_items`、`cdc.base_region`。

### 步骤 6：启动 DWD 处理（Kafka → Iceberg）

> 需要**新终端**，DWD 作业持续运行。

```bash
set -a && source .env && set +a
CP="flink-jobs/target/classes:$(cat /tmp/cp.txt)"

java --add-opens java.base/java.nio=ALL-UNNAMED \
  --add-opens java.base/java.lang=ALL-UNNAMED \
  --add-opens java.base/java.util=ALL-UNNAMED \
  --add-opens java.base/sun.nio.ch=ALL-UNNAMED \
  -cp "$CP" \
  -Dlog4j.configuration=file:$(pwd)/flink-jobs/src/main/resources/log4j.properties \
  com.pipeline.flink.kafka.DwdOrderPaymentJob
```

等待 30 秒，日志出现 Checkpoint 成功记录。

验证：

```bash
ls warehouse/dwd/order_payment_wide/data/*.parquet | wc -l
```

预期：大于 0。

## 三、逐层验证

### PG 层（源库）

```bash
# 查看各表数据量
docker exec pg-cdc psql -U postgres -d ecommerce -c "
  SELECT 'orders' t, count(*) FROM public.orders
  UNION ALL SELECT 'payments', count(*) FROM public.payments
  UNION ALL SELECT 'order_items', count(*) FROM public.order_items
  UNION ALL SELECT 'users', count(*) FROM base.users
  UNION ALL SELECT 'region', count(*) FROM base.region;"
```

### Kafka 层（消息总线）

```bash
# 查看 topic 列表
docker exec kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 --list

# 查看各 topic 消息数（消费一次统计）
for t in cdc.orders cdc.payments cdc.base_region dlq.cdc; do
  count=$(docker exec kafka /opt/kafka/bin/kafka-console-consumer.sh \
    --bootstrap-server localhost:9092 --topic $t --from-beginning \
    --timeout-ms 3000 2>/dev/null | wc -l)
  echo "$t: $count 条"
done

# 消费一条 CDC 消息查看格式
docker exec kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 --topic cdc.orders --from-beginning --max-messages 1
```

### Flink 层（作业状态）

通过日志确认：

```bash
# CDC 作业日志中查找
grep "Pipeline submitted" /path/to/cdc.log

# DWD 作业日志中查找 Checkpoint 成功
grep "Checkpoint.*completed" /path/to/dwd.log
```

### Iceberg 层（数据湖）

```bash
# 查看 parquet 文件
ls -lh warehouse/dwd/order_payment_wide/data/*.parquet

# 查看快照元数据
ls -lh warehouse/dwd/order_payment_wide/metadata/

# 读取 parquet 数据（需 pyarrow）
cd warehouse/dwd/order_payment_wide/data
python3 -c "
import pyarrow.parquet as pq, glob, pyarrow as pa
t = pa.concat_tables([pq.read_table(f) for f in glob.glob('*.parquet')])
print(f'总记录数: {t.num_rows}')
print(f'字段列表: {t.column_names}')
# 维表富化验证
for col in ['region_name', 'user_name', 'user_level']:
    arr = t.column(col)
    print(f'{col} 非空: {len(arr)-arr.null_count}/{len(arr)}')
"
```

## 四、停止与清理

### 停止作业

按依赖逆序停止：

1. **DWD 作业**：`Ctrl+C`
2. **CDC 作业**：`Ctrl+C`
3. **数据生成器**：`Ctrl+C`（如还在运行）

### 清理 Kafka 消费组 offset

重置消费组到最早，下次运行从头消费：

```bash
docker exec kafka /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 \
  --group flink-cdc-pipeline \
  --reset-offsets --to-earliest --all-topics --execute
```

### 清理 Iceberg 数据

```bash
rm -rf warehouse/
```

### 清理 PG 业务数据（保留维表）

```bash
docker exec pg-cdc psql -U postgres -d ecommerce \
  -c "TRUNCATE TABLE public.orders, public.order_items, public.payments CASCADE;"
```

### 停止 Docker

```bash
cd docker
docker-compose down
cd ..
```

> 如需清理 PG 数据卷：`docker-compose down -v`（会删除所有 PG 数据，慎用）。

## 五、故障排查

### 5.1 作业启动失败

| 现象 | 排查 |
|------|------|
| `ClassNotFoundException: SimpleUdfStreamOperatorFactory` | 用 `java -cp` 而非 `mvn exec:java` |
| `InaccessibleObjectException: java.nio.ByteBuffer` | 加 `--add-opens java.base/java.nio=ALL-UNNAMED` |
| `环境变量 XXX 未设置` | 确认 `source .env` 已执行，检查变量名拼写 |
| `Connection refused: localhost:5433` | PG 容器未启动，`docker ps` 检查 |
| `Connection refused: localhost:9092` | Kafka 容器未启动，`docker ps` 检查 |

### 5.2 Kafka 无数据

```bash
# 1. 确认 CDC 作业在运行
ps aux | grep PostgresCdcToKafka

# 2. 确认 PG 有数据
docker exec pg-cdc psql -U postgres -d ecommerce -c "SELECT count(*) FROM public.orders;"

# 3. 确认 CDC topic 存在
docker exec kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 --list

# 4. 检查 CDC 作业日志是否有报错
```

### 5.3 Iceberg 无数据

```bash
# 1. 确认 Kafka 有数据
docker exec kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 --topic cdc.orders --from-beginning --max-messages 1

# 2. 确认 DWD 作业在运行
ps aux | grep DwdOrderPaymentJob

# 3. 检查 DWD 作业日志
#    - 反序列化失败 → 查看 dlq.cdc topic
#    - Checkpoint 失败 → 查看 Kryo/序列化报错
#    - 维表查询失败 → 查看 AsyncIO 报错

# 4. 确认 Iceberg 表是否创建
ls warehouse/dwd/order_payment_wide/
```

### 5.4 Checkpoint 失败

| 报错关键词 | 原因 | 解法 |
|-----------|------|------|
| `KryoException: this.wrapped is null` | Iceberg FlinkWriteResult 序列化 | 确认 `FlinkWriteResultKryoSerializer` 已注册 |
| `Checkpoint expired before completing` | Checkpoint 超时 | 调大 `CHECKPOINT_TIMEOUT_MS` |
| `Too many checkpoints` | Checkpoint 堆积 | 调大 `CHECKPOINT_MIN_PAUSE_MS` |

### 5.5 维表富化失败

| 现象 | 排查 |
|------|------|
| `region_name` 全为空 | region CDC 流未到达，检查 `cdc.base_region` topic |
| `user_name` 全为空 | AsyncIO 查询失败，检查 PG 连接和 `base.users` 表 |
| 部分 `region_name` 为空 | 时序问题（订单先于 region 到达），属正常现象 |

## 六、命令速查

### Docker

```bash
cd docker && docker-compose up -d     # 启动
cd docker && docker-compose down      # 停止（保留数据卷）
cd docker && docker-compose down -v   # 停止并删除数据卷
docker ps                             # 查看运行中的容器
docker logs -f pg-cdc                 # 查看 PG 日志
docker logs -f kafka                  # 查看 Kafka 日志
```

### PostgreSQL

```bash
docker exec pg-cdc psql -U postgres -d ecommerce -c "SQL"  # 执行 SQL
docker exec -it pg-cdc psql -U postgres -d ecommerce       # 交互式
```

### Kafka

```bash
# Topic 列表
docker exec kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 --list

# 消费消息
docker exec kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 --topic <topic> --from-beginning [--max-messages N]

# 重置消费组 offset
docker exec kafka /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 --group flink-cdc-pipeline \
  --reset-offsets --to-earliest --all-topics --execute
```

### Java 作业

```bash
# 构建 classpath

--add-opens java.base/java.lang=ALL-UNNAMED
--add-opens java.base/java.util=ALL-UNNAMED
--add-opens java.base/sun.nio.ch=ALL-UNNAMED
```
