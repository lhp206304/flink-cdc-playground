## 七、建议执行顺序与依赖

```
T2-1 ~ T2-3 (M2 链路1跑通)  ✅
    │
    ▼
T3-1 ~ T3-4 (M3 基础组件)  ✅  →  T3-5/T3-6 (ODS 层)  ❌ 可选
    │
    ▼
T4-3, T4-4, T4-6 (M4 核心)  ✅  →  T4-1(events)/T4-2/T4-5  ❌
    │
    ▼
T5-1, T5-2, T5-4 (M5 维表)  ✅  →  T5-3 (enriched_orders)  ⚠️
    │
    ▼
T6-1 ~ T6-5 (M6 生产增强)  部分
```

**关键路径说明：**

- M2 是整条链路的起点，必须先跑通 CDC → Kafka，后续才有数据可消费。
- M3 基础组件（Source/反序列化/Catalog）已完成，ODS 层单表为可选补全。
- M5 依赖 M4 的订单流，必须等双流处理完成后再做富化。
- M6 为增强项，可在主体链路跑通后逐步补齐。
